# Security Policy

## Supported versions

Security fixes are currently considered for the latest version on the default branch. There are no stable product releases yet.

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in a public GitHub issue or pull request.

Use GitHub's **Report a vulnerability** flow on this repository's Security tab if private vulnerability reporting is enabled. If it is unavailable, contact the repository owner privately through GitHub to arrange a confidential report. Include the affected commit/version, impact, reproduction steps, and any safe proof-of-concept details.

Do not include real Playnite library exports, personal paths, credentials, or private game metadata in a report unless strictly necessary; redact them where possible.

## Response expectations

This is a personal project and does not currently promise a formal response SLA. The maintainer will assess reports, coordinate a fix where appropriate, and avoid public disclosure until a fix or mitigation is available.
